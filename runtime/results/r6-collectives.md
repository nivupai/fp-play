# R6: data for the `#collectives` workspace

Generated by `fp-play-runtime experiment --out results`. `r6-collectives.json` is read by the FP Play app's `#collectives` workspace (`src/lib/collectives/`).

- **Schedules:** for P = 2, 3, 4, 8 and every schedule that supports P, the executed rounds of an AllReduce over 8 elements, each transfer's element range, and each element's association (which ranks' partial sums are added, in which order), traced beside the real simulation.
- **Shard tree:** S = 8 shards at P = 1, 2, 4 and 8: the fixed tree, shard owners and scheduled rounds.
- **Errors:** each schedule's error against the exact sum at every P, copied from `tp-allreduce` in the same run.

Nothing here is a measurement of any system.
